# UI Component Simulator / Simulador de Componentes UI

[EN] A lightweight, single-file visual sandbox designed to build, customize, and preview UI components in real-time without writing code. Ideal for non-programmers and designers looking to experiment with dimensions, colors, and shadows instantly.

[ES] Un entorno interactivo ligero de un solo archivo diseñado para construir, personalizar y previsualizar componentes de interfaz en tiempo real sin escribir código. Ideal para no-programadores y diseñadores que buscan experimentar con dimensiones, colores y sombras al instante.

## Features / Características

### [EN]
* **Single-File Architecture:** Everything runs within a single `index.html` (HTML, CSS, JS) for instant loading and zero deployment issues.
* **Real-Time Simulation:** Modify cards, buttons, layouts, and typography visually.
* **No Code Required:** Fully controlled via intuitive sliders and color pickers.
* **Open for Collaboration:** Structured for community improvements and new component templates.

### [ES]
* **Arquitectura de Archivo Único:** Todo funciona dentro de un solo `index.html` (HTML, CSS, JS) para una carga instantánea y cero problemas de despliegue.
* **Simulación en Tiempo Real:** Modifica tarjetas, botones, estructuras y tipografías de forma visual.
* **Sin Código:** Controlado totalmente mediante sliders y selectores de color intuitivos.
* **Abierto a Colaboración:** Estructurado para recibir mejoras de la comunidad y nuevas plantillas de componentes.
