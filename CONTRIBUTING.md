# Contributing Guidelines / Guía de Contribución

[EN] Thank you for considering contributing to the UI Component Simulator! This project runs entirely on a single-file architecture (`index.html`) to keep it simple, lightweight, and accessible for everyone.

[ES] ¡Gracias por considerar contribuir al Simulador de Componentes UI! Este proyecto funciona completamente sobre una arquitectura de archivo único (`index.html`) para mantenerse simple, ligero y accesible para todos.

---

## How to Contribute / Cómo Colaborar

### 1. Setup the Project / Configurar el Proyecto
* **[EN]** Fork this repository, clone it to your local machine, and simply open the `index.html` file in any modern web browser. No installation or build steps are required.
* **[ES]** Haz un Fork de este repositorio, clónalo en tu computadora y simplemente abre el archivo `index.html` en cualquier navegador web moderno. No se requieren pasos de instalación ni compilación.

### 2. Making Changes / Realizar Cambios
* **[EN]** Since this is a single-file application, please keep all HTML, CSS (inside `<style>`), and JS (inside `<script>`) organized within the `index.html` file.
* **[ES]** Al ser una aplicación de archivo único, por favor mantén todo el HTML, CSS (dentro de `<style>`) y JS (dentro de `<script>`) organizado dentro del mismo archivo `index.html`.
* **[EN]** Write clean, readable code and document your additions so other beginners can understand them.
* **[ES]** Escribe código limpio, legible y documenta tus añadidos para que otros principiantes puedan entenderlos.

### 3. Testing / Pruebas
* **[EN]** Test your modifications in different screen sizes and browsers before submitting your work.
* **[ES]** Prueba tus modificaciones en diferentes tamaños de pantalla y navegadores antes de enviar tu trabajo.

### 4. Submit a Pull Request / Enviar un Pull Request
* **[EN]** Push your changes to your fork and open a Pull Request against the `main` branch. Provide a clear description of the improvements or new components you added.
* **[ES]** Sube tus cambios a tu fork y abre un Pull Request hacia la rama `main`. Proporciona una descripción clara de las mejoras o nuevos componentes que añadiste.

---

## Contribution Ideas / Ideas para Contribuir
* **[EN]** Add new component types (e.g., modern buttons, navigation bars, dropdowns).
* **[ES]** Añadir nuevos tipos de componentes (ej. botones modernos, barras de navegación, menús desplegables).
* **[EN]** Implement new CSS control sliders (e.g., border-radius, backdrop-filter blur, gradients).
* **[ES]** Implementar nuevos sliders de control CSS (ej. esquinas redondeadas, desenfoque de fondo, degradados).
* **[EN]** Improve UI/UX styling for the control panels.
* **[ES]** Mejorar el diseño de interfaz y experiencia de usuario (UI/UX) para los paneles de control.
